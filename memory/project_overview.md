MakoBytes.com is the marketing/landing site for **PromptPixel**, a desktop app that turns screenshots into AI-ready prompts via OCR. Product is $25 one-time purchase.

Existing state (2026-04-09): Initial commit present — single-page `index.html` using Tailwind CDN, SoftwareApplication schema, OG tags, PromptPixel branding. Currently a basic landing page.

**Why:** Russell is building out MakoBytes as the product site for PromptPixel (and likely future MakoBytes apps).
**How to apply:** Treat this as a product landing/storefront. Design should sell the app, not just describe it. SEO matters since it's a real product page.
